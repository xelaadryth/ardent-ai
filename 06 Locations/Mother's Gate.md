# Description
A major transition point within [[Haka'alaku]] that allows for travel between the Physical Realm and [[Shadesmar]]. It is also known as [[Cultivation's Perpendicularity]] or the Horneater Perpendicularity.

As a true descendant of the [[Night]], [[Fina]] feels an unusual resonance with Mother's Gate.

# Current Status
The gate is currently occupied and blockaded by [[The Set]] under the command of [[Johb]]. They use the gate to control the interplanetary trade of [[Nurian Gems]].
