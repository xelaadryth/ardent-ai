# Description

17 co-conspirators shattered Adonalsium into 16 shards using 4 dawnshards that together form the instructions for creation in a cycle.
- Each dawnshard's Command powers the four shards in its quadrant
- Each Command correlates to one of the three realms, plus Temporal from Allomantic theory
- The "contained pair" of shards of each Command are opposites with one intrinsic and one extrinsic that together form the core of the Dawnshard
- The other two shards in the quadrant each form a strong antonym "edge pair" with the shard in the adjacent next quadrant
- "Edge" shards represent the range of intentions of the Command

- DESIGN - Cognitive
    - Ambition
    - Virtuosity
    - Invention
    - Reason
- CHANGE - Temporal
    - Whimsy
    - Cultivation
    - Endowment
    - Ruin
- EXIST - Physical
    - Preservation
    - Autonomy
    - Dominion
    - Mercy
- CONNECT - Spiritual
    - Odium
    - Valor
    - Honor
    - Devotion
